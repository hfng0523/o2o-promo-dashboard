# O2O Promotion Review Dashboard

推廣成效 Review Dashboard（During Promo vs Before Promo）

## 功能
- 5 種比較期間模式（按星期 / 自訂日期 / 工作日週末 / 按月 / 推廣 vs 非推廣）
- 11 個可選 Value（Overall GMV / Senior GMV / Order / Basket Size / Increment / ROI / Usage Rate …）
- 自動建議指標（按推廣類型）
- 店舖 Rank / By AM / By DM / Raw Data 下鑽
- 匯出 CSV / 列印 PDF
